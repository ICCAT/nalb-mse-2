# Atlantic Albacore MSE

Repository containing stock assessment, operating model conditioning,
management strategy evaluation (MSE), reference point estimation,
and management procedure evaluation tools for Atlantic albacore.

## Workflow

```text
Assessment
    |
    v
OM conditioning
    |
    v
OEM generation
    |
    v
MSE simulations
    |
    v
Aggregation and performance evaluation
    |
    v
Advice analyses and Shiny visualisation
```
