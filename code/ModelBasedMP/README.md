# Module: ModelBasedMP

## Purpose

This module implements the model-based management procedure for the North
Atlantic albacore MSE. It fits a SPiCT surplus-production model using
standardised CPUE indices as the assessment method within the MP, and compares
the resulting trajectories against the operating model (OM) reference points
from FLBEIA to evaluate the performance of the procedure.

## Structure

```text
ModelBasedMP/   (no subdirectories)
```

## Active scripts

### `Compare_OM_SPiCT_Run1.R`

Compare OM and MP trajectories from FLBEIA and SPiCT
reference points for a selected scenario.

### `SPiCT_Assessment_CPUE2021.R`

Fit the Atlantic albacore SPiCT assessment using the
standardized CPUE indices available up to 2021.
