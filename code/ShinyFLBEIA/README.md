# Module: ShinyFLBEIA

## Purpose

This module generates the unified input file for the FLBEIAShiny interactive
visualisation app by combining aggregated FLBEIA outputs across all final
management procedure scenarios (model-based, empirical and pseudo-constant catch).

## Structure

```text
ShinyFLBEIA/   (no subdirectories)
```

## Active scripts

### `shiny_FinalScenarios_072026.R`

Combine aggregated FLBEIA outputs from model-based,
empirical and pseudo-constant catch management procedures
and generate a unified input file for FLBEIAShiny.
